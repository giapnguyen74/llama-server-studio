Quick Configuration Presets
Outputs: -c — The prompt context size in tokens.
Detailed explanation
Determines how much previous dialogue and text the model can read. Setting this too high significantly increases VRAM/RAM consumption, potentially leading to slow generations or out-of-memory crashes. Auto-aligns to the selected model's native limit.
Outputs: -ngl — Number of layers offloaded to GPU.
Detailed explanation
Loads model layers directly into GPU memory (VRAM). Increase this to offload more layers and speed up generation. Set to 0 to run purely on the CPU, or configure exact layer counts to fit within your graphics card's available VRAM.
Outputs: -t — CPU cores used during generation.
Detailed explanation
Specifies how many processor threads to allocate. For optimal performance, configure this to match your system's physical (not logical/hyperthreaded) CPU cores. Setting this higher than your physical cores may degrade performance.
Outputs: -b — Logical maximum prompt batch size.
Detailed explanation
Logical maximum batch size for prompt processing. Higher values increase throughput during bulk prompting and benchmarks, but consume more memory during the initial context load.
Outputs: -np — Number of concurrent sessions served.
Detailed explanation
Allocates slot allocations to process multiple requests concurrently. Setting this to 1 keeps memory minimal for single-user workloads, while 2+ enables parallel sessions for team environments or benchmarks.

Security Gateway

Configure authentication keys to secure all proxy completions endpoints across serving profiles.

Gateway API Token

When a token is configured, all requests sent to the Stable Gateway proxy routing endpoints (e.g. /profiles/{id}/v1/...) must supply a valid HTTP Bearer token.

Leave blank to disable authentication on the proxy gateway.

Client Integration Example

To authenticate requests when calling the proxy from client libraries (e.g. OpenAI SDK, LangChain, or cURL): 

curl -X POST http://127.0.0.1:3100/profiles/{profile_id}/v1/chat/completions \
  -H "Authorization: Bearer sk-xyz" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
